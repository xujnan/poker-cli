# 人和 AI agent 共用同一套 CLI，只在输出格式上分岔

这个程序既要给人在终端里玩，也要作为 AI agent 的可对战环境。我们不为 agent 单独提供一套 API，而是让两者共用同一个常驻 REPL 进程和同一套命令，唯一的差别是 `--format`：人类得到排版文本，agent 得到 JSON Lines（每行一个事件对象），阻塞读一行即可事件驱动。

代价是所有输出必须先建模成结构化事件、再由渲染器变成人类文本，不能在代码里直接拼字符串。这正是我们想要的约束：agent 环境的质量完全取决于事件是否结构完整，而共用一套代码路径可以保证人看到的和 agent 收到的永远是同一份事实。
