# 非法动作回报结构化错误并允许有限重试，不直接判负

收到非法动作时服务端回一条错误事件、轮次仍归该玩家；同一轮连续三次非法后，按行动超时规则处理（能 check 就 check，否则 fold）。错误事件同时携带机器可读的 code 与字段（如 `{"code":"min_raise","min":100}`）和给人看的 message。

无限重试会让写坏的 agent 把牌桌卡死，使无人值守的自对弈退化成每 30 秒才推进一步；而把非法动作直接判 fold 又过于残酷，agent 无法从结果反推自己错在哪。结构化错误码是 agent 唯一能据以自动纠错的抓手，它与 ADR-0007 中的合法动作列表构成两道防线：先给出能做什么，再说清为什么不行。
