# 只有一个下注命令 `bet`，且永远是「加注到」语义

`bet 100` 的含义是「把我在当前 Street 上的总投入推到 100」，而不是「在对手基础上再加 100」。我们不提供 `raise` 命令——传统术语里的下注与加注在语义上是同一件事，区别只在此前有没有人下注过。也不提供 `f` / `c` 这类单字母别名。

「加注到」与「再加」的歧义是德州扑克 CLI 最经典的错误来源：两种语义都说得通，一旦人和 agent 各理解成一种，就会下错注且不报错。选 to 语义是因为真实牌桌就这么说话；砍掉 `raise` 是为了让这个歧义在命令表里根本无处存身。不做单字母别名，是因为打错一个字母就弃牌是不可逆的灾难。
