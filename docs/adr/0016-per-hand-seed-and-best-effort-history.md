# 每手牌有自己的种子，历史尽力写但绝不拖住牌桌

牌桌的随机源不再直接拿去洗牌，而是用来为每一手牌抽一个种子；那手牌的牌堆由这个种子单独造出来，种子本身写进 Hand History。于是一条历史记录是自足的：拿着它就能单独重放第 37 手，不必先重放前 36 手。历史文件由一个独立的 goroutine 追加写入，写不动了（磁盘满、缓冲积压）就记一笔并丢弃，牌局照常进行。

「牌桌一个种子」听起来也够用——`--seed` 一样能让整场对局可复现。但那条可复现性是全有或全无的：要复现某一手，就得连同前面每一手的座位顺序、每个人的每个动作原样重来，而这些恰恰是出 bug 时最不确定的东西。ADR-0004 之所以坚持随机源可播种，图的是「给边池分配这类最易出错的逻辑写回归测试」——那要的是「把这一手单独拎出来跑」的能力，不是整场重放。代价是同一个 `--seed` 打出的牌序跟改动之前不同，但可复现性本身更强了。

历史写失败不中断牌局，是因为两者的地位不对等：牌桌是正在发生的事，历史是它的副产物。让一次磁盘错误把三个人的牌局卡死，是拿主要的东西去赔次要的。丢弃会被计数并记进服务端日志，不会静默。
