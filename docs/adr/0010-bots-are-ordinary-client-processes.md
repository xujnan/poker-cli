# 机器人是普通的客户端进程，不内嵌在服务端

`poker bot ABC123 --as bot1` 启动一个独立进程，它连同一个 socket、收同一份 JSONL 事件流、走跟外部 AI agent 完全相同的那条路。服务端不提供 `--bots N` 这种内嵌选项。

内嵌 goroutine 实现起来省事得多，但它与牌桌状态同处一个进程，在技术上能读到所有人的 Hole Cards——ADR-0006 那条可见性不变量对它天然不成立，只能靠自律，而自律不可测。更重要的是：本项目的目标之一是给 AI agent 当可对战环境，让 bot 走 agent 的路，等于每一次本地对战都在回归测试这个环境本身。内嵌的话，agent 接口在第一个真 agent 接入之前不会被验证过哪怕一行。
