# 快速开始一场游戏

从零到坐在牌桌前，大概一分钟。下面每条命令都是真跑出来的，输出也是原样贴的。

**先说一句**：现在只能在**同一台机器**上对战（走 Unix socket，ADR-0001）。
几个人一起打的办法是同一台机器上开几个终端，或者大家 ssh 到同一台机器上。跨机联机还没做。

## 0. 编译

```sh
git clone https://github.com/xujnan/poker-cli && cd poker-cli
go build -o poker ./cmd/poker
```

只要 Go 1.26，没有别的前置。

## 1. 一个终端就能开一局

自己一个人想立刻看到牌，把这几行整段贴进终端：

```sh
./poker serve --code TABLE1 >/dev/null 2>&1 &   # 开桌，日志不要了
sleep 1                                          # 等它把 socket 建好
./poker bot TABLE1 --as bot1 --rebuy >/dev/null 2>&1 &
./poker bot TABLE1 --as bot2 --rebuy >/dev/null 2>&1 &
./poker join TABLE1 --as 我                      # 你自己坐下
```

那个 `sleep 1` 不能省：服务端还没把 socket 建好，机器人连过去会直接退出，
然后你会坐在一张只有自己的桌上等着，看不出哪里不对。

凑够两个有筹码的人就自动开牌，之后每 3 秒一手，不需要谁点「准备」。

打完了收摊（后台那三个进程不会自己走）：

```sh
kill %1 %2 %3
```

## 2. 叫上别人（一人一个终端）

**开桌的人**：

```sh
./poker serve --blinds 1/2
```

```console
牌桌已开：WH8ABC（盲注 1/2，默认带入 200）
加入：poker join WH8ABC --as <你的名字>
监听：/home/you/.poker/WH8ABC.sock
手牌历史：/home/you/.poker/history/WH8ABC-20260920-025458.jsonl
```

把第一行那个 **Table Code** 报给别人就行。自动生成的码避开了 I、O、0、1，
就是为了念给人听的时候不用问「零还是欧」。

想自己挑一个好记的就加 `--code`，那时候这条限制不管你：`--code POKER1`、`--code FRIDAY`
都行，6 位字母数字、不分大小写就成。

**其他人**（在同一台机器上，各开各的终端）：

```sh
./poker join WH8ABC --as alice
./poker join WH8ABC --as bob
```

人不够就拿机器人凑：

```sh
./poker bot WH8ABC --as bot1 --rebuy
```

常用的几个开桌参数：

| 参数 | 干什么 | 默认 |
| --- | --- | --- |
| `--blinds 5/10` | 盲注 | `1/2` |
| `--buyin 500` | 默认带入 | 100 个大盲 |
| `--code FRIDAY` | 自己挑牌桌码 | 随机生成 |
| `--hand-delay 10s` | 一手结束之后等多久开下一手（想看清结果就调大） | `3s` |
| `--timeout 60s` | 单次行动的时限，到点替他「能过牌就过牌，否则弃牌」 | `30s` |
| `--hands 50` | 打满多少手自动收桌 | 不限 |
| `--seed 42` | 固定牌序，方便复现 | 每次都不一样 |

## 3. 屏幕上是什么

对着终端时，屏幕就地重画，永远只显示**正在打的这一手**：

```
第 3 手  河牌  盲注 1/2

  bot1        SB        201  弃
  bot2        BB        195  投 2
▶ 我          BTN       197   9♦ 5♥

公共牌 8♥ J♥ 7♠ 6♦ A♠    底池 7

  ──── 翻牌 8♥ J♥ 7♠ ───────────────────────────
  bot2        过牌
  我          过牌
  ──── 转牌 6♦ ─────────────────────────────────
  bot2        过牌
  我          过牌
  ──── 河牌 A♠ ─────────────────────────────────
  bot2        下注到 2      底池 7

轮到你了    要跟 2
可以：fold / call（跟 2） / bet <4-197> / allin（推 197）
>
```

- `▶` 指着轮到谁；你的底牌只画在你自己那一行，别人看不到。
- `BB` / `BTN` / `SB` 是这手牌的位置——同样两张牌，在 BTN 和在 UTG 是两手完全不同的牌。
- `投 2` 是这条街上已经投进去的，`弃` / `全下` / `暂离` 同理。
- `──── 转牌 3♦ ───` 这样的横线把每条街断开：线以下是新牌面上重新开始的下注。
- 中间那几行是这手牌到目前为止发生了什么，按「谁 / 做了什么 / 底池」三列排，
  人名那一列跟上面座位表是同一条竖线。屏幕多高就显示多少条，矮屏幕上那几个空行会先让位。
- 最后一行 `可以：` 是服务端算好的**合法动作**，照着敲就不会错。

新的一手开始，上面这些全清掉重来。想要一行一条往下滚的流水账就加 `--format=text`。

## 4. 轮到你时能敲什么

```
fold          弃牌
check         过牌
call          跟注
bet <数额>    把本轮总投入推到这个数（不是「再加」这么多）
allin         推光
topup <数额>  补码。随时能发，下一手牌开始前到账
sitout        暂离，这手牌打完生效；座位和筹码都留着
sitin         回座
help / quit
```

**`bet 40` 是「把我本轮总投入推到 40」，不是「再加 40」。** 这是最容易搞错的一条。
没有 `raise`，也没有 `c` / `f` 这种单字母缩写——手一抖就推光了，不值得。

输光了不会被踢出去，会自动暂离；`topup 200` 补上就能接着打。

## 5. 让它自己打（评测、看热闹、跑数据）

```sh
./poker serve --code SOLO23 --hand-delay 0 --timeout 1s --hands 200 &
sleep 1
./poker bot SOLO23 --as bot1 --rebuy &
./poker bot SOLO23 --as bot2 --rebuy &
```

`--hands 200` 打满就自己收桌，不用谁去杀进程——**靠杀进程停下来的一批数据没法拿来比较两个 agent**，
因为停在哪一手是随机的。`--rebuy` 让输光的机器人自动补码，不然桌上剩不到两个有筹码的人就永远停住了。

想自己写 agent 接进来，看 [agent.md](agent.md)：事件表、命令表、错误码表，
外加一个 20 行、不依赖任何库、真能和 `poker bot` 对打的 Python agent（那段代码有测试真跑着）。

## 6. 打完复盘

每手牌都会追加写进 `~/.poker/history/<CODE>-<开桌时间>.jsonl`（`--no-history` 关掉）。
下面的例子用的是一张叫 `POKER1` 的桌，把它换成你自己的码。

```sh
./poker history ~/.poker/history/POKER1-*.jsonl --stats
```

```console
共 13 手牌

玩家             手数     赢   净筹码
bot1               13      6       +2
我                  5      2       +1
bot2               13      5       -3
```

```sh
./poker history ~/.poker/history/POKER1-*.jsonl --hand 2
```

```console
── 第 2 手 ──  POKER1  2026-09-20 02:55:08  盲注 1/2  庄家 bot2
   种子 12449234625241728976
   筹码  bot1 BB 199 | bot2 BTN 201 | 我 SB 200
   底牌  bot1 4♠ K♠ | bot2 Q♦ 6♠ | 我 K♥ J♥

   翻牌前
     bot2       弃牌
     我         跟注 1
     bot1       过牌

   翻牌  4♥ 7♥ 2♦
     我         过牌
     bot1       过牌
   ...
   底池 4 → bot1
   结束  bot1 201 (+2) | bot2 201 (+0) | 我 198 (-2)
```

复盘是上帝视角，所有人的底牌都在里面——所以历史文件别随手发给还在同一张桌上的人。

每条记录都带着自己那一手的种子，单独就能重放出来：

```sh
./poker verify ~/.poker/history/POKER1-*.jsonl
```

```console
重放了 13 手牌，0 手对不上。
```

## 7. 卡住了

**`连不上牌桌 XXXXXX（…）：connect: no such file or directory`**
　没人开这张桌，或者码敲错了。码不分大小写，但必须是 6 位字母数字。
　开桌那边打印的「监听：」那一行就是它要找的文件，对一下路径。

**`无法监听 …: bind: address already in use`**
　同一个码同时只能开一张桌。把旧的那个终端 Ctrl-C 掉（它退出时会自己删掉 socket 文件），
　或者换一个 `--code`。

**坐下了，但一直不开牌**
　要两个**有筹码、没暂离**的人才开得起来。`serve` 那个终端的日志会写「牌桌上共 N 人」。
　常见原因是机器人起早了（见第 1 节那个 `sleep 1`），或者有人输光了还没 `topup`。

**轮到我了，但我在发呆**
　超过 `--timeout`（默认 30 秒）会替你「能过牌就过牌，否则弃牌」，牌桌不会被一个人冻住。

**屏幕花了 / 全是 `\033[12A`**
　输出被重定向到不是终端的地方了。加 `--format=text` 就是干净的纯文本。

**想停下整张桌**
　Ctrl-C 那个 `serve` 终端。它会等最后一手落盘再退出，别急着连按两次。
